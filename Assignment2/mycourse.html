My Academic Journey

I am a first-year B.Tech student pursuing Computer Science Engineering with Artificial Intelligence and Machine Learning at Invertis University. My course introduces me to programming, mathematical concepts, web technologies, and the fundamentals of electrical engineering.

Each subject helps me develop a different skill, from logical thinking and problem-solving to understanding the principles behind electrical circuits and modern technology.

My Subjects

  1. Data Structures and Algorithms (DSA)

    DSA helps me understand how to organise data and solve programming problems efficiently. I am learning Java and practising logical thinking through coding questions.

  2. Web Development

    Web development introduces me to building websites. I am learning HTML and how to structure webpages using headings, links, lists, images, and semantic HTML elements.

  3. Engineering Mathematics

    Engineering Mathematics helps build the mathematical foundation needed for engineering and computing. It develops analytical thinking and problem-solving skills.

  4. Basic Electrical Engineering

    Basic Electrical Engineering introduces me to electrical circuits, their components, and methods of analysing electrical networks.

Tools I Use

These are some of the tools I use for coding, practising programming, and managing my work.

  • Visual Studio Code (VS Code)

    A code editor I use to write and edit HTML and practise web development.

  • Git

    A version control tool that helps me track changes in my code and maintain different stages of my work.

  • IntelliJ IDEA

    An integrated development environment (IDE) I use for Java programming and practising DSA.

What I Am Learning

My current focus is on strengthening my programming fundamentals, improving my logical thinking, learning to build structured webpages, and understanding the concepts taught in my engineering subjects.

I look forward to applying these concepts in future projects and exploring more areas of computer science.
